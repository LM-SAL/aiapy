With ``include_eve_correction=True``, `aiapy.response.Channel` now applies the EVE correction even without an ``obstime``, using the first calibration epoch; previously it was silently skipped.
``Channel.eve_correction`` also defaults to the first calibration epoch.
As with an ``obstime``, this raises an error if the correction table has no calibration for the channel, such as 4500 Å in the SSW tables.
